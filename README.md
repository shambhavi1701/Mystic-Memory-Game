# Mystic Memory

Mystic Memory is a fun, interactive Simon-style memory game built using HTML, CSS, JavaScript and jQuery.
The goal is to remember and repeat the sequence of colors as it grows with each level.

Play here - https://mystic-memory.netlify.app/

## How to Play

- Press START, tap the screen, or press any key.
- Watch the color that lights up.
- Click the same color.
- Each level adds a new color to the sequence.
- Repeat the full sequence correctly to advance.
- One mistake ends the game.
